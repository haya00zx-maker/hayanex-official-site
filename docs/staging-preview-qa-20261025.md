# 非公開プレビュー表示・同期確認手順（2026-10-25）

対象：GitHub `develop` と XServer上のパスワード保護された開発プレビュー。
**2026-10-25時点：外部確認環境からプレビューURLへの接続を確認できず、実機表示・同期状態は未判定。**
アクセス制限の解除、認証情報の共有、公開環境やmainへの反映は不要・禁止。

## 検証開始前の必須条件
- 代表者がご自身のブラウザーで非公開プレビューを開き、アクセス制限が有効であることを確認。
- 現在公開中のサイト・main・DNS・実データに一切変更しない。
- GitHub `develop` からの配置状況を確かめる。**更新コードをGitHubに保存しただけではXServerの表示に反映されない。**
- 試作フォームに実在する氏名・メール・電話・契約情報を入力しない。
- ブラウザーのスクリーンショットを共有する場合、URL内の資格情報・利用者の個人情報を除去。

## GitHub develop とXServerプレビューの同期確認
1. developの最新内容として `index.html` に「サイト制作3プラン、月額保守3プラン、買い切り制作方式」があることを確認。
2. プレビューの料金文面と関連団体説明を比較。相違する場合は**同期未確認/古い配置の可能性**として記録（自動更新とは判断しない）。
3. `faq.html` に「制作費のお支払いは原則一括払い」の説明があるか照合。
4. `legal.html` に旧「契約時50％・納品時50％」が残っていないか確認。
5. 画像・CSS・JS読み込み失敗、ブラウザーコンソールのエラーがないか確認。
6. 不一致は修正候補として台帳に記載。無断でサーバーのファイルを上書きしない。

## 判定基準
- 全チェックを記録するまでは「表示検証完了」としない。
- URLにアクセスできないことだけで「安全な非公開状態」とは断定しない。
- 本番反映は重大不具合なし、法的・個人情報・連絡先等の条件確定、代表者の**明示的な最終承認**が必要。
- 目標日2026-10-31は確約ではない。未完成のフォーム/管理システムは非公開継続。
