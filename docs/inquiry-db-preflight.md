# 非公開開発DB 接続事前確認

**未実施事項**：XServerへのログイン、テストDB作成、実際のDB接続、登録・MFA・権限統合試験。担当者が環境を準備し、代表承認の範囲で非公開テストを行う。

1. XServerのPHP環境でCLI実行可否、PHP 8以上、`pdo_mysql`、`mbstring`、`sodium` を確認。
2. **実際の顧客情報や本番DBを使わず**、名称に `dev` を含む専用DBを作成。本診断は読み取り専用のDBアカウントで実行する。
3. `docs/inquiry-dev-schema.sql` のテーブルはテストDBにのみ適用。適用操作は本スクリプトには含まれない。
4. DBホスト、ユーザー、パスワードをGitHub、サイト画面、管理台帳、ログへ書かず、サーバーの非公開環境変数 `HAYANEX_DEV_DSN`, `HAYANEX_DEV_DB_USER`, `HAYANEX_DEV_DB_PASS` に設定する。
5. リポジトリ内の `dev-only/inquiry/tests/db_preflight.php` を**公開Webルート外のCLIでのみ**実行。ファイルは読み取り専用で、資格情報と個人情報を出力しない。DB名と必須9テーブルのみを照合する。
6. 合格後に、別途「一般スタッフは担当案件のみ」「停止アカウント拒否」「役割変更拒否」「MFAの使用済みコード拒否」の偽データによる統合試験を計画・実行。
7. 無断で公開ブランチmainや現行XServer公開サイト、DNSを変更しない。代表者の最終公開承認が必要。

**確認の限界**：この検査は読み取り専用の事前診断で、接続成功してもアプリケーション全体の安全性・動作を保証しない。

## PHP実行環境の事前診断（DB接続不要）

開発サーバーの非公開ディレクトリで `php dev-only/inquiry/tests/runtime_preflight.php` をCLI実行する。PHP 8.1以上、および pdo_mysql / mbstring / sodium / json の有無を判定する。終了コード0は実行環境の基本要件を満たすことだけを意味し、DBや受付処理の動作保証ではない。終了コード2の場合は不足機能を解消して再実行する。コマンドはDB接続・メール送信・顧客情報の読込みを行わない。公開Webルートには配置しない。
