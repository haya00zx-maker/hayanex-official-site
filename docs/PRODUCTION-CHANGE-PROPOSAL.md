## 本番接続前の技術条件

- サーバーが検証したHTTPSのみ信頼する。任意の`X-Forwarded-Proto`等で認証要件を迂回しない。今回のループバック用共有秘密ヘッダーを本番に流用しない。
- コード・鍵・セッション・バックアップは公開Webルート外。公開入口だけを明示し、SQL・tests・docs・dev-only・.git等を配信しない。
- PDO例外・native prepared statements・InnoDB・utf8mb4・日本時間の取り扱いを確認。`FOR UPDATE SKIP LOCKED`等のSQLが対象DBバージョンで動作することを確認する。
- 本番DB用ユーザーは必要なDMLだけにし、監査は追記専用。DDL用資格情報をWebアプリへ渡さない。
- TOTP鍵はサーバー側で暗号化保管。MFA登録/復旧の本人確認、鍵ローテーションとバックアップ、セッション失効を実地で検証する。
- 新規パスワードにArgon2idを使用。既存bcryptの互換性と72バイトを超えるパスワードの取扱い、対象PHPのアルゴリズム対応を確認する。
- 実通知のプロバイダー・メールの配信要件・宛先・再試行・重複・失敗対応を承認し、fake sinkとは区別する。本番宛先に試験送信しない。
- ブラウザー・実機・支援技術・運用監視・バックアップ復元・切戻しを確認する。
