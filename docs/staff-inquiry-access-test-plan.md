# スタッフ管理画面：閲覧権限の結合確認（非公開開発用）
1. 管理画面へのアクセス前に、DBから最新の利用停止状態と役割を取得する。権限をブラウザ入力から受け取らない。
2. 最高管理者・管理者はすべての案件の受付番号・状態を閲覧できる。
3. 一般スタッフは担当者の割当が一致する行のみ閲覧できる。担当なし・他人担当はSQLのWHERE条件で返さない。
4. 件数上限を100件に制限し、並び順を固定する。権限のない利用者は処理前に拒否する。
5. 顧客情報を管理画面に出力する際はHTMLエスケープ。機密・添付ファイルは別途強制認可が必要。
6. 実装状況：StaffInquiryList.phpは内部呼出専用のDBクエリ部品であり、HTTPログイン、MFA、認証済み画面は未実装。
7. DB接続に必要なPDO MySQLドライバと隔離されたテストDBで、一般スタッフによる他人の案件アクセス拒否を統合テストする。
8. 本番main・DNS・公開環境への反映は代表者の明示的公開承認まで禁止。
