# スタッフ専用ログイン画面：非公開プロトタイプ

`index.html` はHTML/CSSのみで作成した**見た目の確認専用**プレビューです。入力欄とログインボタンは無効化しており、認証情報の送信・保存・セッション発行・DB接続は一切ありません。

VS Codeで `dev-only/staff-preview/index.html` を開き、ブラウザのローカルプレビューでPC・スマートフォン幅を確認できます。

重要：
- 本番用のスタッフログイン画面ではありません。
- `dev-only` 以下の開発資料・検証コードを公開Webルートへアップロードしないでください。
- 実際のログインにはサーバー側のHTTPS/CSRF/レート制限/MFA/セッション管理/DB認証を安全に接続する必要があります。
- GitHub `main` に反映するには代表者の明示的な承認が必要です。
